## Description

PatchBond is a GenLayer StudioNet application for accountable software repair. A client freezes a bug, mandatory requirements, an assigned author, source scope, CI workflow, deadlines, and a fixed simulated GEN reward. The author submits a direct-child Git commit and a successful CI run. Validators independently retrieve pinned before/after source and GitHub metadata, assess every requirement using exact source quotes, and agree on the fields that determine the outcome. Deterministic contract rules enforce a 10-minute challenge window, one challenge per revision, one correction, and fixed reward or refund credits with separate withdrawal. The model never chooses payout amounts or recipients. Verified live flows cover acceptance, a challenged failed patch corrected in revision 2, and expiry/refund through withdrawal. The public app, full source, and evidence are available without sign-in. This is a simulated StudioNet project, not an audited production or real-money service.
